# Disney Infinity Modding Tools (Archive)

> A community archive preserving essential tools, scripts, and utilities for modding **Disney Infinity**.

---

## 📌 Context & Purpose

This repository is an archive dedicated to preserving modding tools for Disney Infinity. Open-source and community tools should remain accessible to everyone rather than being lost or gatekept.

Special thanks to [Darkcranio95](https://github.com/Darkcranio95/Disney-Infinity-Modding-Tools) for preserving these files.

---

## 🧰 Included Tools & Features

| Tool / Folder | Description | Requirements |
| :--- | :--- | :--- |
| **`QuickBMS`** | BMS scripts (`disney_infinity_new.bms`) and binaries for unpacking/reimporting archives. | Windows |
| **`.DCT Converter`** | Python script to convert `.dct` files to XML and back. | Python 3 |
| **`.CHD Parser`** | Parser for `.chd` files for comparison with Lua files. | Python 3 |
| **`.ZIP Reencrypter`** | Offsetting utility to re-encrypt zip archives. | Windows CLI |
| **`C2DITools`** | Scene decryptor and encryptor for `.bent` files. | Python 3 |
| **`gateway.lua Decryptor`** | Node.js script using `crypto-js` to decrypt `gateway.lua`. | Node.js |
| **`(NON BLENDER) Model Viewer`** | Standalone 3D model viewer application. | Windows (.NET / WPF) |
| **`PS4 Texture Converter`** | `Rawtex` utilities for PS4 texture format conversions. | Windows |
| **`PS4 .MTB Fixer`** | Python script to fix PS4 `.mtb` files. | Python 3 |
| **`(OLD) .BENT, .OCT, .MER Converter`** | Legacy tuple decoder script (`decode-tup.py`). | Python 3 |
| **`unluac`** | Java decompiler for Lua bytecode. | Java (JRE) |

---

## ⚙️ Prerequisites

Depending on the tools you use, ensure you have installed:
- [Python 3.x](https://www.python.org/)
- [Node.js](https://nodejs.org/) (for `gateway.lua Decryptor`)
- [Java Runtime Environment](https://www.java.com/) (for `unluac.jar`)
- Windows OS (most binaries and viewers are Windows-native)

---

## 📖 Usage & Documentation

Most folders contain a dedicated `MANUAL.txt` or `HOW TO INSTALL.txt` with specific commands and parameters. Make sure to check each directory for detailed instructions.
